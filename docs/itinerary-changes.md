# Itinerary Changes Policy

- Date or destination changes requested **30+ days before** travel incur a **change fee of 5%** of the package value.
- Changes requested **within 30 days** of travel are treated as a cancellation and rebooking, subject to the Cancellation Policy.
- Itinerary changes are subject to availability and may result in a price difference, payable by the traveler.
- Each booking is eligible for a **maximum of two** free-of-change-fee itinerary modifications per plan terms, if specified in the plan.
- Requests must be submitted in writing via email or the website support form.
